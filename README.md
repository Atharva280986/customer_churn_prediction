# Customer Churn Prediction

## Project Description
This project predicts whether a customer is likely to churn using Machine Learning.

## Files
- preprocess.py - Data preprocessing
- train.py - Model training
- predict.py - Customer churn prediction
- churn_model.pkl - Trained machine learning model
- WA_Fn-UseC_-Telco-Customer-Churn.csv - Dataset

## Version Control Workflow

1. Create a separate branch for every new feature or experiment.
2. Test the changes before merging.
3. Commit changes with a meaningful commit message.
4. Merge successful changes into the main branch.
5. Do not push untested code directly to main.
